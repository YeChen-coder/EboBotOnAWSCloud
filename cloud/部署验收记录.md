## 本地证据与操作

私密目录 `.local/diagnostics/` 已有 SQLite、JSONL 和 JSON 快照，不纳入 Git；`.local/live-verification.json` 为最近一次实时健康检查。首次含 CPU/内存与容器样本的完整采集文件：`20260910T032255Z-evidence.jsonl`、`20260910T032255Z-evidence.snapshot.json`。

在本项目根目录使用已配置的 Python 执行：

```powershell
$EboPython = '<python-executable>'
$env:PYTHONIOENCODING = 'utf-8'
& $EboPython cloud\diagnostic.py collect --minutes 30
& $EboPython cloud\verify.py
& $EboPython cloud\deploy.py status
```

以上为按需采集，未安装无人值守后台采集任务。当前临时 root 登录会话仅用于本次协作部署，不能交给无人值守 LLM；长期诊断应使用独立只读身份，动作执行器使用单独受限身份。AWS DevOps Agent 集成方案已在研究报告中说明，AgentSpace 和托管诊断权限未在本次创建。

需要替换故障 Task 时，可显式使用 `diagnostic.py replace-task --expected-task <当前完整ARN> --reason <原因> --execute`。它检查目标并替换整个 Task，会中断两个容器；本次没有为了测试该操作而额外中断健康服务。

回滚：先 `deploy.py stop`，等待栈更新完成并确认云 Task 停止，然后 `docker start ebo-ai-home-ebo-engine ebo-ai-home-realtime-assistant`。不能在云 Engine 仍运行时启动本地副本。
